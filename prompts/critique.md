# Final UI Critique Prompt

Review the implemented UI without assuming the current design is correct.

Evaluate it against the actual product task and existing system.

Answer internally:

1. What are the three highest-impact usability or hierarchy problems?
2. Which visual choices look generic, decorative, or unjustified?
3. Are there too many cards, containers, badges, pills, gradients, or shadows?
4. Is the information density appropriate for the task?
5. Is the primary action obvious without being excessively loud?
6. Are secondary actions subordinate?
7. Does mobile feel designed rather than merely compressed?
8. Are loading, empty, error, disabled, focus, and success states covered where relevant?
9. Did the implementation preserve the project's design tokens and components?
10. Is any copy filler, redundant, or invented?
11. If Persian text exists, does any file contain U+200C?

Then fix the most important issues that are within the requested scope.
