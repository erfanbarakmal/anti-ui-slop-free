# Reference Analysis Prompt

Use this internally before substantial UI work.

Classify the project and the screen. Then select at most three reference products or platform patterns that are useful for different reasons.

For each selected reference, state only:
- what problem it helps solve
- which principle to borrow
- what must not be copied

Then synthesize a design direction using the current product's existing design system as the visual source of truth.

Do not output a generic moodboard. Do not copy exact layouts. Do not add decorative features just because a reference contains them.
