# Persian Text Rules

## Project Requirement

Persian text must not contain half-space / zero-width non-joiner.

- Forbidden code point: U+200C
- Required separator: U+0020 normal SPACE

Write:

- `می شود`
- `می توان`
- `آن ها`
- `دکمه ها`
- `ویژگی های`

Do not write the equivalent forms using U+200C.

## Validation

Before finishing any task that creates or modifies Persian text, scan relevant text/code files:

```bash
rg -n $'\u200c' .
```

If occurrences were generated by the agent and the user has not overridden this rule, replace them with ordinary spaces.

Do not silently alter third-party vendored code, lock files, binary files, generated dependencies, or external content merely to satisfy this rule.
