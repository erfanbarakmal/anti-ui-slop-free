# Visual Language Rules

## Avoid Generic AI Aesthetics

Treat the following as warning signs, not absolute bans:

- gradient text headlines
- purple/blue neon gradients
- glass panels
- excessive blur
- floating abstract blobs
- massive border radii everywhere
- excessive shadows
- glowing buttons
- arbitrary accent-color badges
- tiny eyebrow copy above every heading
- decorative grids or dots unrelated to function
- excessive pill-shaped controls

Use any of these only when they match an existing brand or solve a real visual problem.

## Specificity Test

Before keeping a major visual choice, ask:

1. Does it reinforce the product's identity or task?
2. Is it consistent with surrounding screens?
3. Does it improve hierarchy, scanning, or affordance?
4. Would removing it make the interface less clear?

If all answers are no, remove it.
