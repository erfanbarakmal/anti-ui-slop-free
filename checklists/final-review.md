# Final Review Checklist

## Product Fit

- [ ] The result looks like part of this product, not a disconnected template.
- [ ] Existing components and tokens are reused where appropriate.
- [ ] No unnecessary product requirements were invented.

## Hierarchy

- [ ] The main task is understandable quickly.
- [ ] Primary and secondary actions are visually distinct.
- [ ] Headings and content order make sense.
- [ ] Decorative labels above headings were not added without purpose.

## Anti-Slop

- [ ] Not everything is a card.
- [ ] Gradients, glows, blur, shadows, and pills are justified if present.
- [ ] No fake metrics, fake charts, or decorative data were invented.
- [ ] No emoji or Unicode glyphs are used as substitute interface icons.
- [ ] Useful information density is appropriate.
- [ ] Filler copy has been removed.

## Interaction

- [ ] Every visible control works or is intentionally documented as a placeholder.
- [ ] Hover/focus/active/disabled/selected states are coherent where relevant.
- [ ] Loading, empty, and error states exist where relevant.
- [ ] Destructive actions are handled safely.

## Responsive

- [ ] Narrow mobile layout is intentional.
- [ ] Navigation adapts instead of clipping.
- [ ] Long labels do not break controls unexpectedly.
- [ ] Important actions remain reachable.

## Accessibility

- [ ] Semantic elements are used.
- [ ] Keyboard use is supported.
- [ ] Focus is visible.
- [ ] Form labels and errors are accessible.
- [ ] Color is not the only signal.
- [ ] Motion respects reduced-motion preferences when applicable.

## Persian

- [ ] Persian text contains no U+200C half-space.
- [ ] Normal U+0020 spaces are used instead.
