# Pre-Build Checklist

- [ ] I understand the main user task.
- [ ] I inspected existing screens/components.
- [ ] I identified existing typography, spacing, colors, radii, borders, and icons.
- [ ] I know the primary action and primary information.
- [ ] I know what should remain secondary.
- [ ] I am not adding invented product requirements.
- [ ] I chose layout patterns based on the task, not on generic dashboard habits.
- [ ] I identified responsive constraints.
- [ ] I identified relevant loading/empty/error/interaction states.
- [ ] If Persian copy is involved, I will use normal spaces and no U+200C.
