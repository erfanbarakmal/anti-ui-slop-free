# Web Reference Pass

Before implementing a substantial UI with live reference research:

- [ ] I know the screen's primary user task.
- [ ] Live search will materially help, rather than add noise.
- [ ] Search is available without forcing an unrequested paid dependency.
- [ ] Queries describe tasks/workflows instead of vague style adjectives.
- [ ] I preferred official, primary, or reputable open-source sources.
- [ ] I selected no more than three final references.
- [ ] Each reference has a distinct purpose.
- [ ] I know whether each source was search-only, text-readable, image-visible, or source-code-accessible.
- [ ] I did not infer visual details from search snippets alone.
- [ ] I extracted patterns, not pixels.
- [ ] I preserved the current product's visual identity unless redesign was requested.
- [ ] I avoided exact branded composition and proprietary assets.
- [ ] I have a fallback if search is unavailable or weak.
- [ ] RTL rules are applied when relevant.
- [ ] Persian text contains no U+200C.
