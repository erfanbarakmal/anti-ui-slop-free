# Free Reference Method

This skill does not require a commercial UI reference database.

## Reference Priority

Use references in this order:

1. The current product.
2. User-provided screenshots/designs.
3. Existing Storybook/component examples.
4. Platform conventions.
5. Public examples from products solving a similar task.
6. Open-source applications solving a similar task.

## What to Extract

Extract principles, not pixels:

- information hierarchy
- navigation model
- content density
- interaction sequence
- table/list/form choice
- responsive behavior
- error and empty-state handling
- placement of primary actions
- progressive disclosure

## What Not to Copy

Do not copy:

- logos
- proprietary illustrations
- brand-specific visual assets
- exact page compositions
- unique trade dress
- copywriting verbatim
- proprietary data

The goal is informed design reasoning, not visual cloning.
